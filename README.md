# VFS Shell Emulator

Эмулятор командной оболочки UNIX-подобной ОС на языке Java с графическим интерфейсом Swing.

**Дисциплина:** Конфигурационное управление  
**Вариант:** №1

## Описание

Приложение предоставляет графический интерфейс для выполнения команд в интерактивном режиме (REPL).

Реализованы:
- Разбор команд и аргументов, обработка ошибок.
- Настройка параметров запуска.
- CSV-логирование вызовов команд и ошибок.
- Выполнение стартовых скриптов с остановкой при первой ошибке.
- Загрузка виртуальной файловой системы (VFS) из JSON.
- Работа с файлами и каталогами VFS.
- Изменение владельцев файлов и каталогов в оперативной памяти.

## Команды

| Команда | Описание |
|---|---|
| `ls [path]` | Выводит содержимое каталога или имя файла |
| `cd path` | Изменяет текущий каталог |
| `du [path]` | Выводит размер файла или каталога в байтах |
| `date` | Выводит текущую дату и время |
| `chown owner path` | Изменяет владельца файла или каталога |
| `vfs-init` | Сбрасывает VFS к состоянию по умолчанию |
| `exit` | Завершает работу эмулятора |

Поддерживаются абсолютные и относительные пути, включая `.` и `..`.

Команда `chown` изменяет владельца только в оперативной памяти, не затрагивая исходный JSON.

## Параметры запуска

| Параметр | Описание |
|---|---|
| `--vfs` | Путь к JSON-файлу виртуальной файловой системы |
| `--log` | Путь к CSV-файлу логирования |
| `--script` | Путь к стартовому скрипту |

При запуске параметры отображаются в графическом окне.

CSV-лог содержит поля `timestamp`, `command`, `arguments`, `error`.

Стартовые скрипты выполняют команды последовательно и останавливаются при первой ошибке.

## Виртуальная файловая система

VFS загружается из JSON с использованием библиотеки Gson и хранится в оперативной памяти.

Поддерживаются вложенные файлы и каталоги, владельцы объектов и содержимое файлов в формате Base64.

Примеры VFS находятся в папке `data`:

- `minimal.json` — пустая VFS.
- `several.json` — несколько файлов и каталогов.
- `deep.json` — многоуровневая структура каталогов.

Все обычные операции выполняются в памяти. Исключение — `vfs-init`, которая сбрасывает VFS и перезаписывает её физическое представление, если указан JSON-файл.

## Сборка и запуск

**Требования:** Windows, JDK 17 или новее, Apache Maven.

Сборка выполняется через Maven.

Обычный запуск:

```powershell
.\run.bat
```

Запуск с параметрами:

```powershell
.\run.bat --vfs data\deep.json --log logs\commands.csv
```

Запуск со стартовым скриптом:

```powershell
.\run.bat --vfs data\deep.json --script tests\stage5-error.txt
```

## Примеры использования

```text
$ ls /
etc
home

$ cd /home/user/projects
Текущий каталог: /home/user/projects

$ ls
readme.txt

$ du readme.txt
5    /home/user/projects/readme.txt

$ chown alice readme.txt
Владелец /home/user/projects/readme.txt изменён на alice

$ chown bob /missing
Ошибка: chown: путь не найден: /missing

$ date
```

Команда `date` выводит текущую дату и время компьютера.

При неправильных аргументах и несуществующих путях выводятся сообщения об ошибках.

## Тестирование

Компиляция проекта и тестов:

```powershell
mvn -q test-compile dependency:copy-dependencies
```

Запуск автоматических тестов:

```powershell
java -cp "target\classes;target\test-classes;target\dependency\*" CommandProcessorTest
java -cp "target\classes;target\test-classes;target\dependency\*" Stage2Test
java -cp "target\classes;target\test-classes;target\dependency\*" Stage3Test
java -cp "target\classes;target\test-classes;target\dependency\*" Stage4Test
java -cp "target\classes;target\test-classes;target\dependency\*" Stage5Test
```

Проверка команд и обработки ошибок через стартовые скрипты:

```powershell
.\tests\test-stage5.bat
```

Тесты проверяют команды, конфигурацию, логирование, загрузку VFS, работу с каталогами, изменение владельцев и сохранность исходного JSON после `chown`.
