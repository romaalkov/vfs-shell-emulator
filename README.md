# VFS Shell Emulator

Эмулятор командной оболочки UNIX-подобной ОС на языке Java с графическим интерфейсом Swing.

**Дисциплина:** Конфигурационное управление  
**Вариант:** №1

## Описание

Приложение предоставляет графический интерфейс для ввода и выполнения команд в интерактивном режиме (REPL).

Реализованы:
- Разбор команд и аргументов, обработка ошибок.
- Настройка параметров запуска.
- CSV-логирование команд и ошибок.
- Выполнение стартовых скриптов с остановкой при первой ошибке.
- Загрузка виртуальной файловой системы (VFS) из JSON в оперативную память.
- Работа с файлами и каталогами виртуальной файловой системы.

## Команды

| Команда | Описание |
|---|---|
| `ls [path]` | Выводит содержимое каталога или имя файла |
| `cd path` | Изменяет текущий каталог |
| `du [path]` | Выводит размер файла или каталога в байтах |
| `date` | Выводит текущую дату и время |
| `vfs-init` | Сбрасывает VFS к состоянию по умолчанию |
| `exit` | Завершает работу эмулятора |

Команды поддерживают абсолютные и относительные пути, включая `.` и `..`.

Предусмотрена обработка неизвестных команд, неверных аргументов и несуществующих путей.

## Параметры запуска

| Параметр | Описание |
|---|---|
| `--vfs` | Путь к JSON-файлу виртуальной файловой системы |
| `--log` | Путь к CSV-файлу логирования |
| `--script` | Путь к стартовому скрипту |

При запуске параметры отображаются в графическом окне.

CSV-лог содержит поля `timestamp`, `command`, `arguments`, `error`.

Стартовый скрипт выполняет команды последовательно с отображением ввода и вывода. При первой ошибке выполнение останавливается.

## Виртуальная файловая система

VFS загружается из JSON-файла с использованием библиотеки Gson.

Поддерживаются:
- Файлы и каталоги с вложенной структурой.
- Имена и владельцы объектов.
- Содержимое файлов в формате Base64.
- Проверка корректности структуры VFS.
- Обработка ошибок загрузки.

Операции выполняются в оперативной памяти без изменения исходного JSON, за исключением команды `vfs-init`, которая сбрасывает VFS и её физическое представление.

Примеры VFS находятся в папке `data`:

- `minimal.json` — пустая VFS.
- `several.json` — несколько файлов и каталогов.
- `deep.json` — многоуровневая структура каталогов.

## Сборка и запуск

**Требования:** Windows, JDK 17 или новее, Apache Maven.

Сборка выполняется через Maven с подключением Gson.

Обычный запуск:

```powershell
.\run.bat
```

Запуск с параметрами:

```powershell
.\run.bat --vfs data\deep.json --log logs\commands.csv
```

Запуск со стартовым скриптом:

```powershell
.\run.bat --vfs data\deep.json --script tests\stage4-ok.txt
```

## Примеры использования

Для VFS из `data/deep.json`:

```text
$ ls /
etc
home

$ cd /home/user/projects
Текущий каталог: /home/user/projects

$ ls
readme.txt

$ du readme.txt
5    /home/user/projects/readme.txt

$ du /
11    /

$ date
```

Команда `date` выводит актуальную дату и время компьютера.

Примеры обработки ошибок:

```text
$ cd /missing
Ошибка: cd: путь не найден: /missing

$ ls /unknown
Ошибка: ls: путь не найден: /unknown

$ date extra
Ошибка: date не принимает аргументы
```

Сброс VFS:

```text
$ vfs-init
VFS сброшена. VFS: каталогов 1, файлов 0
```

**Внимание:** `vfs-init` изменяет исходный JSON при запуске с параметром `--vfs`. Для проверки команды следует использовать временную копию VFS.

## Тестирование

Компиляция проекта и тестов:

```powershell
mvn -q test-compile dependency:copy-dependencies
```

Запуск автоматических тестов:

```powershell
java -cp "target\classes;target\test-classes;target\dependency\*" CommandProcessorTest
java -cp "target\classes;target\test-classes;target\dependency\*" Stage2Test
java -cp "target\classes;target\test-classes;target\dependency\*" Stage3Test
java -cp "target\classes;target\test-classes;target\dependency\*" Stage4Test
```

Проверка команд четвёртого этапа и обработки ошибок:

```powershell
.\tests\test-stage4.bat
```

Тесты проверяют обработку команд, конфигурацию, логирование, загрузку VFS, работу с файлами и каталогами, подсчёт размеров и обработку ошибок.
