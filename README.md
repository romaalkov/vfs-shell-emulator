# VFS Shell Emulator

Эмулятор командной оболочки UNIX-подобной ОС на языке Java с графическим интерфейсом Swing.

**Дисциплина:** Конфигурационное управление  
**Вариант:** №1

## Описание

Приложение предоставляет графический интерфейс для ввода и выполнения команд в интерактивном режиме (REPL).

Реализованы:
- Разбор команд и аргументов, обработка ошибок.
- Настройка параметров запуска.
- CSV-логирование вызовов команд и ошибок.
- Выполнение стартовых скриптов с остановкой при первой ошибке.
- Загрузка виртуальной файловой системы (VFS) из JSON-файла в оперативную память.
- Проверка структуры VFS и корректности Base64.
- Сброс виртуальной файловой системы.

## Команды

| Команда | Описание |
|---|---|
| `ls [path]` | Выводит название команды и аргументы |
| `cd path` | Выводит название команды и аргумент |
| `exit` | Завершает работу эмулятора |
| `vfs-init` | Сбрасывает VFS к состоянию по умолчанию |

Команды `ls` и `cd` пока работают как заглушки.

Команда `vfs-init` создаёт пустую VFS с корневым каталогом. Если VFS загружена из JSON-файла, его содержимое также заменяется на VFS по умолчанию.

## Параметры запуска

| Параметр | Описание |
|---|---|
| `--vfs` | Путь к JSON-файлу виртуальной файловой системы |
| `--log` | Путь к CSV-файлу логирования |
| `--script` | Путь к стартовому скрипту |

При запуске параметры отображаются в графическом окне.

CSV-лог содержит поля `timestamp`, `command`, `arguments`, `error`.

Стартовый скрипт выполняет команды последовательно, отображая ввод и вывод в окне эмулятора. При первой ошибке выполнение скрипта останавливается.

## Виртуальная файловая система

VFS загружается из JSON-файла с использованием библиотеки Gson.

Поддерживаются:
- Файлы и каталоги с произвольной вложенностью.
- Имена и владельцы объектов.
- Содержимое файлов в формате Base64.
- Проверка корректности JSON и структуры VFS.
- Обработка ошибок загрузки.

Обычные операции выполняются в оперативной памяти без изменения исходного JSON. Исключение — служебная команда `vfs-init`.

В папке `data` находятся примеры:

| Файл | Содержимое |
|---|---|
| `minimal.json` | Пустой корневой каталог |
| `several.json` | Несколько файлов и каталогов |
| `deep.json` | Вложенная структура с несколькими уровнями |

## Сборка и запуск

**Требования:** Windows, JDK 17 или новее, Apache Maven.

Сборка выполняется через Maven с подключением Gson.

Обычный запуск:

```powershell
.\run.bat
```

Запуск с параметрами:

```powershell
.\run.bat --vfs data\deep.json --log logs\commands.csv
```

Запуск со стартовым скриптом:

```powershell
.\run.bat --script tests\stage3-error.txt
```

## Примеры использования

```text
$ ls documents
ls: [documents]

$ cd home
cd: [home]

$ hello
Ошибка: неизвестная команда 'hello'

$ vfs-init
VFS сброшена. VFS: каталогов 1, файлов 0

$ exit
Выход из эмулятора
```

**Внимание:** команда `vfs-init` перезаписывает исходный JSON-файл, если он указан. Для проверки сброса следует использовать временную копию VFS.

## Тестирование

Компиляция проекта и тестов:

```powershell
mvn -q test-compile dependency:copy-dependencies
```

Запуск автоматических тестов:

```powershell
java -cp "target\classes;target\test-classes;target\dependency\*" CommandProcessorTest
java -cp "target\classes;target\test-classes;target\dependency\*" Stage2Test
java -cp "target\classes;target\test-classes;target\dependency\*" Stage3Test
```

Проверка работы с различными VFS:

```powershell
.\tests\test-vfs-minimal.bat
.\tests\test-vfs-several.bat
.\tests\test-vfs-deep.bat
```

Тесты проверяют обработку команд, конфигурацию, CSV-логирование, загрузку разных VFS, сброс файловой системы и обработку ошибок.
