# VFS Shell Emulator

Эмулятор командной оболочки UNIX-подобной ОС на языке Java с графическим интерфейсом Swing.

**Дисциплина:** Конфигурационное управление  
**Вариант:** №1

## Описание

Приложение предоставляет графический интерфейс для ввода и выполнения команд в интерактивном режиме (REPL).

Реализованы разбор команд и аргументов, обработка ошибок, настройка параметров запуска, CSV-логирование и выполнение стартовых скриптов.

## Реализованные команды

| Команда | Описание |
|---|---|
| `ls [path]` | Выводит название команды и аргументы |
| `cd path` | Выводит название команды и аргумент |
| `exit` | Завершает работу эмулятора |

Команды `ls` и `cd` работают как заглушки.

## Параметры запуска

| Параметр | Описание |
|---|---|
| `--vfs` | Путь к файлу VFS |
| `--log` | Путь к CSV-файлу логирования |
| `--script` | Путь к стартовому скрипту |

При запуске значения параметров выводятся в графическом окне.

**Логирование:** события вызова команд записываются в CSV-файл с полями `timestamp`, `command`, `arguments`, `error`.

**Стартовый скрипт:** команды из текстового файла выполняются последовательно с отображением ввода и вывода. При первой ошибке выполнение скрипта останавливается.

## Сборка и запуск

**Требования:** Windows, JDK 17 или новее.

Запуск приложения из корневой папки проекта:

```powershell
.\run.bat
```

Запуск с параметрами:

```powershell
.\run.bat --vfs data\example.json --log logs\commands.csv --script tests\startup-ok.txt
```

Ручная компиляция (папка `out` должна существовать):

```powershell
javac -encoding UTF-8 -d out src\*.java
java -cp out Main
```

## Примеры использования

```text
$ ls
ls: []

$ ls documents
ls: [documents]

$ cd home
cd: [home]

$ cd
Ошибка: cd требует один аргумент

$ hello
Ошибка: неизвестная команда 'hello'

$ exit
Выход из эмулятора
```

## Тестирование

Компиляция тестов (после сборки приложения):

```powershell
javac -encoding UTF-8 -cp out -d out tests\*.java
```

Запуск тестов:

```powershell
java -cp out CommandProcessorTest
java -cp out Stage2Test
```

Проверка параметров запуска и стартовых скриптов:

```powershell
.\tests\test-config-all.bat
.\tests\test-config-no-script.bat
.\tests\test-config-error.bat
```

Тесты проверяют обработку команд, аргументы запуска, CSV-логирование и ошибки. Стартовые скрипты дополнительно проверяются через BAT-файлы.
