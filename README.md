# VFS Shell Emulator

Эмулятор командной оболочки UNIX-подобной операционной системы, разработанный на языке Java.

**Дисциплина:** Конфигурационное управление  
**Вариант:** №1  
**Язык программирования:** Java  
**Графический интерфейс:** Java Swing

## 1. Описание проекта

Приложение представляет собой эмулятор командной оболочки UNIX с графическим интерфейсом пользователя (GUI).

На первом этапе реализован REPL (Read-Eval-Print Loop) — интерактивный режим, позволяющий пользователю вводить команды, выполнять их обработку и получать результат.

Команды `ls` и `cd` на данном этапе являются заглушками и выводят своё название и переданные аргументы.

## 2. Функциональность первого этапа

Реализованы следующие возможности:

- Графический интерфейс с использованием Java Swing.
- Отображение имени VFS в заголовке окна.
- Ввод команд через текстовое поле.
- Разделение введённой строки на название команды и аргументы по пробелам.
- Обработка неизвестных команд.
- Проверка количества аргументов команд.
- Реализация команд-заглушек `ls` и `cd`.
- Завершение работы приложения командой `exit`.

### Поддерживаемые команды

| Команда | Описание |
|---|---|
| `ls` | Выводит название команды без аргументов |
| `ls path` | Выводит название команды и переданный аргумент |
| `cd path` | Выводит название команды и переданный аргумент |
| `exit` | Завершает работу эмулятора |

На первом этапе команды `ls` и `cd` не выполняют операций с файловой системой.

### Обработка ошибок

Предусмотрена обработка следующих ситуаций:

- Ввод неизвестной команды.
- Отсутствие обязательного аргумента команды `cd`.
- Передача более одного аргумента команде `ls`.
- Передача аргументов команде `exit`.
- Передача более одного аргумента команде `cd`.

## 4. Требования для запуска

Для работы приложения необходимо:

- Windows.
- Java JDK 17 или новее.

Дополнительные библиотеки для выполнения первого этапа не требуются.

## 5. Сборка и запуск

Открыть терминал в корневой папке проекта и выполнить:

```bat
run.bat
```

Скрипт компилирует Java-файлы из папки `src` в папку `out` и запускает приложение.

Также можно выполнить команды вручную:

```bat
javac -encoding UTF-8 -d out src\*.java
java -cp out Main
```

Перед ручной компиляцией необходимо создать папку `out`, если она отсутствует.

## 6. Примеры использования

После запуска приложения откроется графическое окно эмулятора.

**Пример 1. Команда ls без аргументов**

```text
$ ls
ls: []
```

**Пример 2. Команда ls с аргументом**

```text
$ ls documents
ls: [documents]
```

**Пример 3. Команда cd с аргументом**

```text
$ cd home
cd: [home]
```

**Пример 4. Неизвестная команда**

```text
$ hello
Ошибка: неизвестная команда 'hello'
```

**Пример 5. Команда cd без аргументов**

```text
$ cd
Ошибка: cd требует один аргумент
```

**Пример 6. Команда ls с неправильными аргументами**

```text
$ ls a b
Ошибка: ls принимает не более одного аргумента
```

**Пример 7. Команда exit с аргументом**

```text
$ exit 123
Ошибка: exit не принимает аргументы
```

**Пример 8. Завершение работы**

```text
$ exit
Выход из эмулятора
```

После выполнения команды `exit` окно приложения закрывается.

## 7. Тестирование

Для проверки работы команд используется класс `CommandProcessorTest`.

После компиляции основного приложения необходимо выполнить в корневой папке проекта:

```bat
javac -encoding UTF-8 -cp out -d out tests\CommandProcessorTest.java
java -cp out CommandProcessorTest
```

Тесты проверяют:

- Выполнение `ls` без аргументов.
- Выполнение `ls` с аргументом.
- Выполнение `cd` с аргументом.
- Обработку неправильных аргументов.
- Обработку неизвестных команд.
- Корректное завершение работы по команде `exit`.

При успешном прохождении тестов выводится сообщение:

```text
Все тесты пройдены!
```
